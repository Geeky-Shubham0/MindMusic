# MindMusic 🎧🧠

AI-Driven Music App that detects your brain state using a simulated API and opens matching Spotify music in your browser.

## Features
- Detects brain state: Relaxed, Focused, or Stressed
- Opens curated music on Spotify based on detected state
- Built with JavaFX and Java Desktop API

1. Clone the repo
2. Run `MainApp.java` (ensure JavaFX is configured)
3. Click "Detect Brain State" ➜ Click "Play Spotify Music"
